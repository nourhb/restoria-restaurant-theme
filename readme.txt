== Description ==

Restoria is an elegant Full Site Editing theme crafted for restaurants and fine dining — deep charcoal and warm cream design with a burnt-sienna accent. Reservation hero with table-booking CTA, hours/location info bar, our-story section, signature-dishes grid, full tabbed menu, chef profile, testimonials, gallery, private-events section, animated stats, contact info and a booking CTA — everything a restaurant needs to fill tables online.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and "Midnight" + "Cream" style variations. Translation-ready and accessibility-conscious.
