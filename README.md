# Restoria — Restaurant & Fine Dining WordPress Theme

An elegant Full Site Editing (block) theme for restaurants and fine dining establishments.

## Design

- Deep charcoal (`#1a1512`) + warm cream (`#faf6f0`) with burnt-sienna terracotta accent (`#c2410c`) and olive secondary (`#5b6236`)
- Reservation hero with pulsing "Reserve a Table" badge
- Hours, location and phone prominent in the header top bar
- Inter typeface (bundled, OFL licensed)
- "Midnight" dark and "Cream" light style variations included

## Templates

| Template | Purpose |
|---|---|
| `front-page.html` | Hero, info bar, story, signature dishes, stats, chef, testimonials, gallery, private events, booking CTA |
| `page-menu.html` | Full menu + signature dishes + booking CTA |
| `page-about.html` | Story, chef profile + stats + booking CTA |
| `page-reservations.html` | Reservation form + info bar + private events |
| `page-contact.html` | Contact info |
| `page.html` / `page-wide.html` | Standard and wide page layouts |
| `single.html`, `archive.html`, `search.html`, `index.html`, `404.html` | Blog and utility templates |
